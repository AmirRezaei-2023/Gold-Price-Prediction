# 🪙 Gold Price Prediction with AI & Time Series

> **Predicting gold prices using Machine Learning and ARIMA time-series modeling**

This project explores the prediction of **gold prices** using two complementary approaches: **Artificial Intelligence / Machine Learning** and the classical **ARIMA time-series model**.

The goal is to compare data-driven machine learning methods with statistical time-series forecasting and investigate their ability to capture patterns in historical gold-price data.

## 🔍 Approaches

### 🤖 Machine Learning
The project applies machine learning techniques to historical market data to identify patterns and relationships that can be used for price prediction.

### 📈 ARIMA
**ARIMA (AutoRegressive Integrated Moving Average)** is used as a classical time-series forecasting approach, capturing trends and temporal dependencies in historical gold prices.

## 🎯 Objective

The main objective is to understand how **machine learning and statistical time-series methods** perform when forecasting financial data, while analyzing the patterns and limitations of each approach.
